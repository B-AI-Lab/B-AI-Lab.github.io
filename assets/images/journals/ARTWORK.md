# Website journal identification artwork

`trends-neuroscience-education-custom.webp` is original artwork created for the B.AI Lab website: independently composed typography, background and abstract network geometry. It contains no Elsevier cover image, crop, cover illustration, traced element or reconstructed publisher logo. The journal title, publisher name and ISSN are plain factual identification labels. This is an in-house identification graphic, not an official publisher cover or logo.

The raster artwork uses the website's existing RUB Inter fonts. Their embedded licence metadata identifies SIL Open Font License 1.1, copyright 2016 The Inter Project Authors. The [OFL FAQ, sections 1.1 and 1.1.1](https://openfontlicense.org/ofl-faq/) permits original graphics made using these fonts without imposing the font licence on the resulting artwork.

## Restored journal visuals

The website owner explicitly authorized public display of the selected third-party journal visuals on 25 October 2026. This authorization records the owner's publication decision; it is not a publisher licence or confirmation of third-party copyright or trademark permission. Applicable third-party reuse permissions remain unconfirmed. Public availability of a source and article-level open-access licences are not treated as blanket rights to journal covers or branding. These assets are accurately marked `USER_AUTHORIZED_PUBLICATION_RIGHTS_UNCONFIRMED` in the research JSON.

The restored files are byte-identical to the approved local preview. No replacement icons or new image treatments were introduced. The original Elsevier Trends cover remains excluded; this publication uses only the in-house graphic above. The Anatomical Sciences Education and Mind, Brain, and Education covers are archival low-resolution thumbnails, preserved at their approved sizes. All images retain text fallbacks.
